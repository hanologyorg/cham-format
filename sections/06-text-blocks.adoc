[[text-blocks]]
== Text blocks

Text blocks are the primary content units of a CHAM file.
The text between the frontmatter closing `---` and the first annotation section heading (`##`) is parsed as text blocks.

=== Blank line semantics

The number of blank lines between content lines determines their structural relationship:

[cols="1,1,3"]
|===
| Blank lines | Semantic | Description

| 0 (consecutive lines)
| Continuation
| Lines belong to the same text block. Line breaks within the block do not affect annotation offsets.

| 1 (single blank line)
| Block boundary
| New text block. In poetry: a new line/verse. In prose: a new paragraph.

| 2+ (multiple blank lines)
| Structural break
| New section. In poetry: a new stanza. In prose: a major structural division.
|===

=== Poetry text

In poetry mode (`genre: poetry`), each verse line is followed by a single blank line.
Stanzas are separated by two or more blank lines.

[source]
----
力拔山兮氣蓋世。

時不利兮{1}騅{/1}不逝。

{1}騅{/1}不逝兮可奈何！


虞兮虞兮{2}奈若何{/2}！
----

[example]
====
The blank line after "可奈何！" is followed by another blank line, creating a 2-blank-line gap — this is a structural break separating the two stanzas.
The file contains *2 sections* and *4 text blocks*.
====

=== Prose text

In prose mode (`genre: prose`), consecutive lines without blank lines are *continuations* — they are merged into a single text block.
Line breaks within a continuation block do not affect annotation character offsets.

[source]
----
{1}道{/1}可道，非常{2}道{/2}。
{3}名{/3}可名，非常{4}名{/4}。

無名天地之始，有名萬物之母。
故常無欲，以觀其妙；
常有欲，以觀其徼。
----

[example]
====
The first two lines form one text block (no blank line between them).
The single blank line creates a block boundary.
The next three lines form a second text block.
The file contains *1 section* and *2 text blocks*.
====

=== Section and block indexing

Parsers *shall* assign indices as follows:

* *Sections* are numbered sequentially starting from 0, each separated by 2+ blank lines.
* *Text blocks* are numbered sequentially within each section, starting from 0.
* Character offsets are calculated within each text block independently (see <<inline-markers>>).
