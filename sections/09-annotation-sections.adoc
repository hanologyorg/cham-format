[[annotation-sections]]
== Annotation sections

=== Section structure

A CHAM file may contain multiple annotation sections, each introduced by a `##` (Markdown level-2 heading).
Each section represents a distinct annotation layer.

All sections in a file share the same marker table — inline marker IDs are file-scoped, not section-scoped.

[source]
----
## 注釋
( modern annotations )

## 王弼註
@contributor: A010
@role: annotator
@dynasty: 三國（魏）
@nature: commentary
( Wang Bi's annotations )

## 白話譯文
@contributor: A050
@role: translator
@nature: translation
( translation entries )
----

=== Section metadata

Metadata lines follow the section heading, using the `@key:value` syntax.
They appear immediately after the `##` heading and continue until the first non-`@` line.

[cols="1,3"]
|===
| Key | Description

| `@contributor`
| Contributor ID (references `authors.yaml`)

| `@role`
| Role: `annotator` \| `translator` \| `editor`

| `@dynasty`
| Dynasty of the contributor

| `@era`
| Era name (年號)

| `@era_year`
| Year within the era

| `@iso`
| ISO/CE year

| `@nature`
| Nature: `annotation` \| `commentary` \| `translation` \| `exegesis` \| `notes`
|===

=== Commentary types

The classical Chinese scholarly tradition has a rich taxonomy of commentary types.
The `@nature` field *should* use one of the following defined values:

[cols="1,1,3"]
|===
| Value | Chinese | Description

| `zhuan`
| 傳
| Early exegesis that transmits and explains the classic (e.g., 左傳, 公羊傳)

| `gu`
| 故/詁
| Glosses explaining archaic words (e.g., 毛詩故訓傳)

| `zhu`
| 注
| Direct annotation of the text (e.g., 鄭玄注, 何晏注)

| `zhangju`
| 章句
| Chapter-and-verse commentary with parsing and explanation

| `jian`
| 箋
| Supplementary notes that correct and expand on an earlier commentary (e.g., 鄭箋 on 毛傳)

| `jijie`
| 集解
| Collected explanations from multiple commentators (e.g., 何晏《論語集解》)

| `jizhu`
| 集注
| Collected annotations (e.g., 朱熹《四書集注》)

| `shu`
| 疏
| Sub-commentary that explicates both the text and earlier annotations (e.g., 孔穎達《五經正義》)

| `zhengyi`
| 正義
| Official sub-commentary commissioned by the state (functionally equivalent to `shu`)

| `yinyi`
| 音義
| Pronunciation and meaning notes (e.g., 陸德明《經典釋文》)

| `kaozheng`
| 考證
| Qing dynasty evidential scholarship

| `pingdian`
| 評點
| Literary criticism with commentary and evaluation
|===

The hierarchy of the classical commentary tradition follows:

[source]
----
          Text（經文/原文）
         /       \
       zhuan      gu（傳/詁）
         |
        zhu（注）
       /    \
     jian   jijie（箋/集解）
       |
      shu/zhengyi（疏/正義）
       |
     kaozheng（考證）
----

=== Default section

The `## 注釋` section is the default annotation section.
It *may* omit all metadata (defaulting to `nature: annotation`).
All other sections *should* include at minimum `@contributor` and `@nature`.

=== Section semantics

Annotation sections provide a way to organize annotations by source within a single file.
They are distinct from multi-file annotation layers (<<multi-file>>), which use separate files.
Both mechanisms use the same marker table and can coexist.
